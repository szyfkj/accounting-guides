# 面向非会计人员的会计指南

用通俗语言讲解记账和企业税务，面向不是会计的企业主、经理和员工。

## 从这里开始

1. **[会计基础](fundamentals/index.md)** 讲解任何国家的会计体系都通用的概念：会计恒等式、借方与贷方、分类账和财务报表。
2. **国家指南** 讲解各国法规：谁必须记账、主要税种、申报期限和罚则。
