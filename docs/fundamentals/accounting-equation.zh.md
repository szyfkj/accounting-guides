# 会计恒等式

所有会计体系都建立在一个等式之上，而且它必须始终平衡：

$$
\text{资产} = \text{负债} + \text{所有者权益}
$$

通俗地说：企业拥有的一切，要么用借来的钱（负债）购买，要么用股东的钱（所有者权益）购买。

## 五类账户

账簿中的每个账户都属于以下五类之一。

| 类别 | 含义 | 举例 |
| --- | --- | --- |
| 资产 | 企业拥有或应收的东西 | 现金、银行存款、应收账款、存货、车辆、电脑 |
| 负债 | 企业欠他人的款项 | 应付账款、银行贷款、应交增值税、应交代扣税、应付工资 |
| 所有者权益 | 股东的权益 | 实缴股本、留存收益 |
| 收入 | 从客户处赚取的价值 | 销售收入、服务费、利息收入 |
| 费用 | 为取得收入而耗用的成本 | 销售成本、租金、工资、电费、折旧 |

收入和费用最终影响所有者权益。利润（收入减费用）使权益增加，亏损使权益减少。因此扩展后的等式为：

$$
\text{资产} = \text{负债} + \text{所有者权益} + (\text{收入} - \text{费用})
$$

## 一个简单例子

Somchai 开了一家咖啡店公司。

1. 股东投入 1,000,000 泰铢。资产（银行存款）+1,000,000；权益（股本）+1,000,000。
2. 公司向银行借款 500,000 泰铢。资产（银行存款）+500,000；负债（借款）+500,000。
3. 购买一台 300,000 泰铢的咖啡机。资产（银行存款）−300,000；资产（设备）+300,000。总资产不变。
4. 现金销售咖啡 50,000 泰铢。资产（现金）+50,000；收入 +50,000。
5. 支付房租 20,000 泰铢。资产（银行存款）−20,000；费用 +20,000。

五笔交易之后：资产 1,530,000 泰铢，负债 500,000，权益 1,000,000，利润 30,000。1,530,000 = 500,000 + 1,000,000 + 30,000，等式始终平衡。
