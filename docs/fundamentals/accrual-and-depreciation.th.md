# เกณฑ์เงินสดกับเกณฑ์คงค้าง และค่าเสื่อมราคา

ประเทศส่วนใหญ่กำหนดให้บริษัทใช้ **เกณฑ์คงค้าง (accrual basis)**: บันทึกรายได้เมื่อเกิดสิทธิได้รับ และบันทึกค่าใช้จ่ายเมื่อเกิดขึ้น ไม่ใช่เมื่อมีการรับจ่ายเงิน กฎหมายภาษีมักใช้หลักเดียวกันนี้

|  | เกณฑ์เงินสด | เกณฑ์คงค้าง (บังคับสำหรับบริษัทส่วนใหญ่) |
| --- | --- | --- |
| บันทึกรายได้เมื่อ | ได้รับเงิน | ส่งมอบสินค้าหรือให้บริการเสร็จ |
| บันทึกค่าใช้จ่ายเมื่อ | จ่ายเงิน | ได้รับสินค้าหรือบริการ |
| ใบแจ้งหนี้เดือนธันวาคม จ่ายเดือนมกราคม | รายได้เดือนมกราคม | รายได้เดือนธันวาคม |
| แสดง | การเคลื่อนไหวของเงินสด | กำไรที่แท้จริงของงวด |

## รายการปรับปรุงสิ้นงวดที่พบบ่อย

- **ค่าใช้จ่ายค้างจ่าย** ค่าไฟเดือนธันวาคมที่ได้รับบิลเดือนมกราคม ยังเป็นค่าใช้จ่ายเดือนธันวาคม: Dr ค่าไฟฟ้า, Cr ค่าใช้จ่ายค้างจ่าย
- **ค่าใช้จ่ายจ่ายล่วงหน้า** เบี้ยประกัน 12 เดือนที่จ่ายในเดือนตุลาคมต้องเฉลี่ยตลอด 12 เดือน เป็นค่าใช้จ่ายปีนี้เพียง 3 เดือน ส่วนที่เหลือเป็นสินทรัพย์
- **รายได้รับล่วงหน้า** เงินมัดจำจากลูกค้าสำหรับงานที่ยังไม่ได้ทำ เป็นหนี้สิน ไม่ใช่รายได้
- **หนี้สูญ** โดยทั่วไปตัดหนี้สูญได้เมื่อดำเนินการติดตามทวงถามตามเงื่อนไขที่กฎหมายกำหนดแล้ว ควรปรึกษานักบัญชีก่อนตัดหนี้สูญ

## ค่าเสื่อมราคา

สินทรัพย์ที่ใช้งานได้หลายปี เช่น รถยนต์หรือคอมพิวเตอร์ ไม่ใช่ค่าใช้จ่ายทั้งหมดในวันที่ซื้อ ต้นทุนจะถูกเฉลี่ยตามจำนวนปีที่ใช้งาน ส่วนของแต่ละปีคือค่าเสื่อมราคา

$$
\text{ค่าเสื่อมราคาต่อปี (วิธีเส้นตรง)} = \frac{\text{ราคาทุน} - \text{มูลค่าคงเหลือ}}{\text{อายุการใช้งาน (ปี)}}
$$

ตัวอย่าง: โน้ตบุ๊กราคา 90,000 บาท ใช้งาน 3 ปี ไม่มีมูลค่าคงเหลือ ค่าเสื่อมราคาปีละ 30,000 บาท

กฎภาษีเรื่องค่าเสื่อมราคาและหนี้สูญแตกต่างกันในแต่ละประเทศ ดู [ประเทศไทย: ภาษีเงินได้นิติบุคคล](../thailand/corporate-income-tax.md#tax-rules-for-depreciation-and-bad-debts)
