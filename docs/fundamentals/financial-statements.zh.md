# 财务报表

财务报表是账簿的年度汇总。公司通常需将其提交给公司登记机关和税务机关。主要有四张报表加附注。

| 报表 | 回答的问题 | 期间 |
| --- | --- | --- |
| 财务状况表（资产负债表） | 我们拥有什么、欠什么？ | 某一日期（如 12 月 31 日） |
| 利润表（损益表） | 我们赚钱了吗？ | 一个期间（如全年） |
| 所有者权益变动表 | 股东权益如何变化？ | 一个期间 |
| 现金流量表 | 现金从哪里来、到哪里去？ | 一个期间 |
| 附注 | 数字背后的政策和细节 | — |

许多国家允许小型私人公司采用简化准则，无需编制现金流量表，但它对经营管理仍然很有用。

## 如何看利润表

| 项目 | 泰铢 | 关注点 |
| --- | --- | --- |
| 营业收入 | 5,000,000 | 是否增长？哪些产品或客户贡献最大？ |
| 销售成本 | (3,000,000) | 所售商品的直接成本 |
| **毛利** | **2,000,000** | 毛利率 40%。毛利率下降意味着定价过低或成本上升 |
| 销售及管理费用 | (1,400,000) | 租金、工资、营销、水电 |
| **营业利润** | **600,000** | 主营业务的利润 |
| 财务费用 | (50,000) | 借款利息 |
| **税前利润** | **550,000** | 计算企业所得税的起点 |
| 所得税 | (37,500) | 示例，详见各国指南 |
| **净利润** | **512,500** | 转入留存收益 |

所得税一行仅为示例，采用泰国的 SME 税率：前 300,000 按 0%，其余 250,000 按 15%。详见 [泰国：企业所得税](../thailand/corporate-income-tax.md)。

## 每月值得检查的四个数字

- **银行存款 vs. 未来 30 天到期的账单。** 利润不等于现金，盈利的公司也可能资金断裂。
- **应收账款账龄。** 客户付款越来越晚是一个预警信号。
- **毛利率 %。** 毛利 ÷ 营业收入，关注趋势。
- **流动比率。** 流动资产 ÷ 流动负债。低于 1 表示短期债务超过短期资源。
