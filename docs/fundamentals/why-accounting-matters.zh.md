# 为什么会计很重要

会计是记录企业每一笔资金往来、并把这些记录整理成可信报表的体系。在大多数国家，记账也是公司的一项法定义务，应缴税款也依据账簿计算。具体规定请参阅你所在国家的指南。

**记账（Bookkeeping）** 是日常记录：每一笔销售、采购、付款和收款都要连同原始凭证登记。**会计（Accounting）** 范围更广：对记录进行分类、期末调整，并编制财务报表。

良好的账簿带来三大好处：

- **控制。** 清楚谁欠你钱、你欠谁钱、手上真实有多少现金。
- **决策。** 看清哪些产品、客户或分店在赚钱。
- **合规。** 向税务机关和公司登记机关提交的申报都以账簿为基础。账目混乱意味着税额出错、罚款以及审查时的麻烦。

请记住一条简单规则：**没有凭证，就不入账。** 账上的每一笔记录都必须有发票、收据、合同或银行对账单作为依据。
