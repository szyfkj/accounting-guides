# 单据：税务发票、收据与电子税务发票

在泰国，费用扣除或进项税抵扣是否有效，取决于背后的单据。信息错误或缺失是税务稽查中费用被剔除的最常见原因。

## 常见商业单据

| 单据 | 泰文 | 用途 |
| --- | --- | --- |
| 报价单 | ใบเสนอราคา | 报价，不入账 |
| 发票 / 请款单 | ใบแจ้งหนี้ / ใบวางบิล | 要求客户付款 |
| 税务发票 | ใบกำกับภาษี | 载明所收增值税；买方抵扣进项税的凭证 |
| 收据 | ใบเสร็จรับเงิน | 证明已收到款项 |
| 贷项通知单 / 借项通知单 | ใบลดหนี้ / ใบเพิ่มหนี้ | 调减或调增原税务发票（退货、折扣、调价） |
| 代扣税证明 | 50 ทวิ | 证明已代扣税款（见 [预提所得税](withholding-tax.md)） |
| 替代收据 | ใบรับรองแทนใบเสร็จ | 出租车、市场摊贩等无法开收据时，由员工签字证明 |

泰国企业常把几种单据合并为一张，例如"税务发票/收据"（ใบกำกับภาษี/ใบเสร็จรับเงิน）。

## 完整税务发票必须载明的内容

根据《税法典》第 86/4 条，完整税务发票必须包括：

- [ ] 醒目标明"税务发票"（ใบกำกับภาษี）字样
- [ ] 卖方名称、地址和 13 位税号
- [ ] 买方名称、地址和税号（买方为增值税登记人时）
- [ ] 卖方和买方的总部或分支机构编号（สำนักงานใหญ่ 或 สาขาที่ 00001）
- [ ] 发票序号（如有册号也需注明）
- [ ] 商品或服务的名称、种类、数量和金额
- [ ] 增值税额与价格分开列示
- [ ] 开票日期

付款前用这份清单检查采购发票。公司名称、地址或分支机构有误时，请供应商重开。

## 何时开具税务发票

税务发票在 **纳税义务发生时点** 开具，这也决定了增值税归属的月份：

- **商品：** 交付、转移所有权、收款或开票，以最先发生者为准。
- **服务：** 收到付款时，或更早开具税务发票时。

## 简易税务发票

零售商可开具简易税务发票（ใบกำกับภาษีแบบย่อ），通常由在税务局登记的 POS 机打印。买方 **不能** 凭它抵扣进项税。为公司采购时，请索取完整税务发票。

## 电子税务发票与电子收据

税务局的 [e-Tax Invoice & e-Receipt](https://etax.rd.go.th) 系统允许企业以电子方式代替纸质开具这些单据。小型企业可使用"电子邮件"方式，大型企业可直接传送数据。开具和接收电子单据尚非强制，但可节省打印和存储，且根据现行优惠，买方对部分 e-Tax 费用可按更高比例扣除。
