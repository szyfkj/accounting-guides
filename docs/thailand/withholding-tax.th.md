# ภาษีหัก ณ ที่จ่าย (Withholding Tax, WHT)

เมื่อบริษัทจ่ายค่าบริการ ค่าเช่า และเงินได้บางประเภท ต้อง **หักภาษีไว้ตามอัตราที่กำหนดและนำส่งกรมสรรพากร** แทนผู้รับเงิน เป็นการชำระภาษีล่วงหน้าของผู้รับเงิน ไม่ใช่ภาษีเพิ่ม: ผู้รับเงินนำไปเครดิตภาษีเงินได้นิติบุคคลหรือบุคคลธรรมดาของตนได้

ภาษีหัก ณ ที่จ่ายคำนวณจากยอด **ก่อน VAT** และโดยทั่วไปใช้กับการจ่ายตั้งแต่ 1,000 บาทขึ้นไป

## อัตราที่พบบ่อยสำหรับการจ่ายให้บริษัทไทย

| ประเภทการจ่าย | อัตรา |
| --- | --- |
| ค่าบริการ ค่าวิชาชีพ ค่าจ้างทำของ | 3% |
| ค่าเช่าอสังหาริมทรัพย์หรืออุปกรณ์ | 5% |
| ค่าโฆษณา | 2% |
| ค่าขนส่ง (ไม่ใช่ขนส่งสาธารณะ) | 1% |
| ดอกเบี้ย | 1% |
| รางวัลและการส่งเสริมการขาย | 5% |
| เงินปันผล | 10% |

อัตราสำหรับการจ่ายให้บุคคลธรรมดาและบริษัทต่างประเทศแตกต่างกัน การจ่ายไปต่างประเทศสำหรับค่าบริการ ค่าสิทธิ และดอกเบี้ย โดยทั่วไปหัก 15% และเงินปันผล 10% เว้นแต่อนุสัญญาภาษีซ้อนกำหนดอัตราต่ำกว่า ([Forvis Mazars](https://forvismazars.com/th/en/insights/doing-business-in-thailand/tax/withholding-tax-in-thailand))

**e-Withholding Tax** การจ่ายผ่านระบบ e-WHT ของธนาคาร ทำให้หักเพียง 1% แทน 2–5% และธนาคารยื่นแบบให้ คณะรัฐมนตรีอนุมัติขยายเวลาตั้งแต่ 1 มกราคม 2569 ถึง 31 ธันวาคม 2570 แต่ยังต้องประกาศในราชกิจจานุเบกษา ควรตรวจสอบก่อนใช้ ([Forvis Mazars](https://www.forvismazars.com/th/en/insights/doing-business-in-thailand/tax/thailand-extends-e-tax-and-e-donation-incentives))

## แบบที่ต้องยื่น

| แบบ | ใช้สำหรับการจ่ายให้ |
| --- | --- |
| ภ.ง.ด.1 | พนักงาน (เงินเดือนและค่าจ้าง) |
| ภ.ง.ด.2 | บุคคลธรรมดาที่ได้รับเงินปันผลหรือดอกเบี้ย |
| ภ.ง.ด.3 | บุคคลธรรมดา (ฟรีแลนซ์ เจ้าของที่ ผู้รับเหมา) |
| ภ.ง.ด.53 | บริษัทและห้างหุ้นส่วนนิติบุคคลในไทย |
| ภ.ง.ด.54 | บริษัทต่างประเทศที่ไม่ได้ประกอบกิจการในไทย |

ยื่นและชำระภายใน **วันที่ 7 ของเดือนถัดไป** (วันที่ 15 หากยื่นทางอินเทอร์เน็ต)

## หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ)

ผู้จ่ายต้องออกหนังสือรับรองให้ผู้รับเงิน เรียกว่า "50 ทวิ" ตามมาตรา 50 ทวิ แห่งประมวลรัษฎากร ในฐานะผู้รับเงิน **เก็บรวบรวมหนังสือรับรองทุกฉบับที่ได้รับ** เพราะเป็นหลักฐานในการเครดิตภาษีใน ภ.ง.ด.50 หากหนังสือหาย อาจต้องเสียภาษีซ้ำสองครั้ง

ตัวอย่าง: คุณจ่ายค่าบริการการตลาดให้เอเจนซี่ไทย 50,000 บาท + VAT 3,500 หัก 3% ของ 50,000 = 1,500 บาท โอนให้เอเจนซี่ 52,000 บาท ยื่น ภ.ง.ด.53 ภายในวันที่ 7 (วันที่ 15 หากยื่นออนไลน์) และออก 50 ทวิ 1,500 บาทให้เอเจนซี่
