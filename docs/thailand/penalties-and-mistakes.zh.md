# 罚则与常见错误

逾期缴税代价很高：欠缴税款每月加收 **1.5% 的滞纳金**（最高不超过税额本身），另加罚款。按时申报，即使没有应纳税额，也能避免大部分罚则。

## 主要罚则

| 问题 | 后果 |
| --- | --- |
| 逾期缴税 | 按欠缴税额每月（不足一月按一月）加收 1.5% 滞纳金（《税法典》第 27 条） |
| 逾期申报 | 刑事罚金（一般每份申报最高 2,000 泰铢），应纳税额另加滞纳金 |
| 增值税少报或未申报 | 最高 2 倍税额的罚款；在税务局联系前自愿补报可减少；另加滞纳金 |
| 未开税务发票，或未登记增值税却开具税务发票 | 2 倍税额的罚款及罚金 |
| 未代扣税款，或已代扣但未缴纳 | 付款方须自行承担该税款及滞纳金，相关费用还可能不得扣除 |
| 未设账，或未向 DBD 提交财务报表 | 依《会计法》对公司罚款，并另对董事罚款 |

金额由法律规定且可能调整；税务局公布了自愿逾期申报的罚款减免标准。

## 非会计人员常犯的错误

1. **公私不分。** 使用独立的公司银行账户。通过公司支付的个人开支不得税前扣除，还可能被视为董事的收入。
2. **接受信息有误的采购发票。** 缺少税号或分支机构有误，进项税就不能抵扣。
3. **忘记对服务费和租金代扣税款**，结果只能自己补缴。
4. **没有收集客户开具的 50 Tawi**，导致已被代扣的税款无法抵减。
5. **忽略增值税登记门槛。** 收入超过 180 万泰铢后，无论是否向客户收取，都要就销售额缴纳增值税。
6. **把银行存款当成利润。** 其中一部分是属于政府的增值税、代扣税和社保。
7. **拖到年底才处理。** 每月记账和银行对账能让审计更快、更便宜。
8. **签署自己不理解的文件。** 即使由会计公司编制，董事仍对部分申报承担个人责任。
