# Thailand

Bookkeeping duties and the main taxes for businesses in Thailand.

> **Important:** This guide is for education only. Thai tax rates, thresholds and deadlines change, often by royal decree for a set period. Always confirm current rules with the [Revenue Department](https://www.rd.go.th) or a licensed accountant before you file or make a decision.
