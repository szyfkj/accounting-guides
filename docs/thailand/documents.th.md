# เอกสาร: ใบกำกับภาษี ใบเสร็จ และ e-Tax Invoice

ในประเทศไทย การหักรายจ่ายหรือขอคืนภาษีซื้อดีได้เท่ากับเอกสารประกอบ ข้อมูลผิดหรือไม่ครบเป็นสาเหตุที่พบบ่อยที่สุดที่รายจ่ายถูกตัดออกเมื่อถูกตรวจสอบภาษี

## เอกสารธุรกิจที่พบบ่อย

| เอกสาร | อังกฤษ | วัตถุประสงค์ |
| --- | --- | --- |
| ใบเสนอราคา | Quotation | เสนอราคา ไม่มีการบันทึกบัญชี |
| ใบแจ้งหนี้ / ใบวางบิล | Invoice / Billing note | แจ้งให้ลูกค้าชำระเงิน |
| ใบกำกับภาษี | Tax invoice | แสดง VAT ที่เรียกเก็บ เป็นหลักฐานของผู้ซื้อในการขอคืนภาษีซื้อ |
| ใบเสร็จรับเงิน | Receipt | พิสูจน์ว่าได้รับเงินแล้ว |
| ใบลดหนี้ / ใบเพิ่มหนี้ | Credit note / Debit note | ลดหรือเพิ่มยอดใบกำกับภาษีเดิม (คืนสินค้า ส่วนลด เปลี่ยนราคา) |
| หนังสือรับรองการหักภาษี ณ ที่จ่าย | Withholding tax certificate (50 Tawi) | พิสูจน์ว่ามีการหักภาษี (ดู [ภาษีหัก ณ ที่จ่าย](withholding-tax.md)) |
| ใบรับรองแทนใบเสร็จ | Substitute receipt | พนักงานลงนามรับรองเมื่อผู้ขายรายย่อย เช่น แท็กซี่หรือแม่ค้าในตลาด ออกใบเสร็จไม่ได้ |

ธุรกิจไทยมักรวมเอกสารไว้ในฉบับเดียว เช่น "ใบกำกับภาษี/ใบเสร็จรับเงิน"

## ใบกำกับภาษีเต็มรูปต้องมีอะไรบ้าง

ตามมาตรา 86/4 แห่งประมวลรัษฎากร ใบกำกับภาษีเต็มรูปต้องมี:

- [ ] คำว่า "ใบกำกับภาษี" ในที่ที่เห็นได้ชัดเจน
- [ ] ชื่อ ที่อยู่ และเลขประจำตัวผู้เสียภาษี 13 หลักของผู้ขาย
- [ ] ชื่อ ที่อยู่ และเลขประจำตัวผู้เสียภาษีของผู้ซื้อ (กรณีผู้ซื้อจด VAT)
- [ ] สำนักงานใหญ่หรือเลขสาขาของผู้ขายและผู้ซื้อ (เช่น สาขาที่ 00001)
- [ ] เลขที่ของใบกำกับภาษี (และเล่มที่ ถ้ามี)
- [ ] ชื่อ ชนิด ประเภท ปริมาณ และมูลค่าของสินค้าหรือบริการ
- [ ] จำนวน VAT แยกออกจากราคาสินค้า
- [ ] วัน เดือน ปี ที่ออก

ใช้รายการนี้ตรวจใบกำกับภาษีซื้อก่อนจ่ายเงิน หากชื่อบริษัท ที่อยู่ หรือสาขาไม่ถูกต้อง ให้ผู้ขายออกใหม่

## ออกใบกำกับภาษีเมื่อใด

ใบกำกับภาษีออกเมื่อ **ความรับผิดในการเสียภาษี** เกิดขึ้น ซึ่งกำหนดว่า VAT นั้นเป็นของเดือนใดด้วย:

- **สินค้า:** เมื่อส่งมอบ โอนกรรมสิทธิ์ ได้รับชำระเงิน หรือออกใบกำกับภาษี แล้วแต่อย่างใดเกิดก่อน
- **บริการ:** เมื่อได้รับชำระเงิน หรือออกใบกำกับภาษีก่อนหน้านั้น

## ใบกำกับภาษีอย่างย่อ

ผู้ค้าปลีกออกใบกำกับภาษีอย่างย่อได้ มักออกจากเครื่อง POS ที่ได้รับอนุมัติจากกรมสรรพากร ผู้ซื้อ **ไม่สามารถ** ใช้ขอคืนภาษีซื้อได้ หากซื้อในนามบริษัท ให้ขอใบกำกับภาษีเต็มรูป

## e-Tax Invoice และ e-Receipt

ระบบ [e-Tax Invoice & e-Receipt](https://etax.rd.go.th) ของกรมสรรพากรช่วยให้ออกเอกสารเหล่านี้เป็นอิเล็กทรอนิกส์แทนกระดาษ กิจการขนาดเล็กใช้แบบ "ทางอีเมล" ได้ ส่วนกิจการขนาดใหญ่ส่งข้อมูลตรง การออกและรับเอกสารอิเล็กทรอนิกส์ยังไม่บังคับ แต่ช่วยประหยัดการพิมพ์และการจัดเก็บ และผู้ซื้อหักค่าใช้จ่าย e-Tax บางรายการได้ในอัตราที่สูงกว่าตามมาตรการส่งเสริมปัจจุบัน
