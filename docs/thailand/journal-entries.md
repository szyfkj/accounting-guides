# Journal entries for common Thai transactions

These worked entries show how Thai VAT, withholding tax and social security appear in the books. See [Debits and credits](../fundamentals/debits-and-credits.md) for the rules.

These are typical Thai transactions for a VAT-registered company. Amounts are in baht.

**a) Sell services for 10,000 + 7% VAT on credit**

| Account | Dr | Cr |
| --- | --- | --- |
| Accounts receivable | 10,700 |  |
| Service income |  | 10,000 |
| Output VAT |  | 700 |

**b) Customer pays, after withholding 3% tax on the 10,000 fee**

| Account | Dr | Cr |
| --- | --- | --- |
| Bank | 10,400 |  |
| Prepaid withholding tax (asset) | 300 |  |
| Accounts receivable |  | 10,700 |

The 300 baht is not lost. The customer pays it to the Revenue Department for you and gives you a withholding tax certificate. You later credit it against your corporate income tax.

**c) Buy office supplies for 2,000 + 7% VAT, paid by transfer**

| Account | Dr | Cr |
| --- | --- | --- |
| Office supplies expense | 2,000 |  |
| Input VAT | 140 |  |
| Bank |  | 2,140 |

**d) Pay a 50,000 monthly salary; deduct 875 social security and 1,700 personal income tax**

| Account | Dr | Cr |
| --- | --- | --- |
| Salary expense | 50,000 |  |
| Social security payable |  | 875 |
| Withholding tax payable (PND 1) |  | 1,700 |
| Bank |  | 47,425 |

The employer also owes its own 875 baht social security share: Dr Social security expense 875, Cr Social security payable 875. Both payables are cleared when the company pays the Social Security Office and the Revenue Department the next month.

In each entry, check that the Dr column total equals the Cr column total. If they differ, there is an error.
