# 术语表

| 中文 | 泰文 | 英文 | 含义 |
| --- | --- | --- | --- |
| 会计期间 | รอบบัญชี | Accounting period | 一套财务报表涵盖的 12 个月 |
| 应付账款 | เจ้าหนี้การค้า | Accounts payable | 欠供应商的款项 |
| 应收账款 | ลูกหนี้การค้า | Accounts receivable | 客户欠你的款项 |
| 权责发生制 | เกณฑ์คงค้าง | Accrual basis | 收入在赚取时确认，费用在发生时确认 |
| 资产 | สินทรัพย์ | Asset | 企业拥有或控制且有价值的东西 |
| 注册会计师（审计师） | ผู้สอบบัญชีรับอนุญาต | Auditor (CPA) | 审计财务报表的持牌独立会计师 |
| 资产负债表 | งบแสดงฐานะการเงิน | Balance sheet | 某一日期的资产、负债和权益报表 |
| 记账人 | ผู้ทำบัญชี | Bookkeeper | 依《会计法》负责登记交易的人 |
| 企业所得税 | ภาษีเงินได้นิติบุคคล | Corporate income tax | 对公司净利润征收的税 |
| 销售成本 | ต้นทุนขาย | Cost of goods sold | 当期所售商品的直接成本 |
| 贷方 | เครดิต | Credit | 分录右边；增加负债、权益和收入 |
| 借方 | เดบิต | Debit | 分录左边；增加资产和费用 |
| 折旧 | ค่าเสื่อมราคา | Depreciation | 在使用年限内分摊资产成本 |
| 所有者权益 | ส่วนของผู้ถือหุ้น | Equity | 股东的权益：股本加留存利润 |
| 费用 | ค่าใช้จ่าย | Expense | 为取得收入而耗用的成本 |
| 财务报表 | งบการเงิน | Financial statements | 汇总账簿的年度报告 |
| 总分类账 | บัญชีแยกประเภท | General ledger | 按账户归类的全部交易记录 |
| 利润表 | งบกำไรขาดทุน | Income statement | 某期间收入、费用和利润的报表 |
| 进项税额 | ภาษีซื้อ | Input VAT | 采购时支付的增值税 |
| 存货 | สินค้าคงเหลือ | Inventory | 待售商品 |
| 日记账 | สมุดรายวัน | Journal | 按日期顺序的原始记录簿 |
| 负债 | หนี้สิน | Liability | 企业欠他人的款项 |
| 销项税额 | ภาษีขาย | Output VAT | 销售时收取的增值税 |
| 实缴资本 | ทุนชำระแล้ว | Paid-up capital | 股东实际缴入的股本 |
| 个人所得税 | ภาษีเงินได้บุคคลธรรมดา | Personal income tax | 对个人收入征收的税 |
| 留存收益 | กำไรสะสม | Retained earnings | 留在企业内的历年利润 |
| 营业收入 | รายได้ | Revenue | 销售商品和服务的收入 |
| 社会保险 | ประกันสังคม | Social security | 由雇主和员工共同缴费的国家保险 |
| 税号 | เลขประจำตัวผู้เสียภาษีอากร | Tax ID | 13 位纳税人识别号 |
| 税务发票 | ใบกำกับภาษี | Tax invoice | 已登记卖方开具的增值税单据 |
| 试算平衡表 | งบทดลอง | Trial balance | 所有账户余额清单，借方必须等于贷方 |
| 增值税 | ภาษีมูลค่าเพิ่ม | VAT | 由登记企业收取的 7% 商品和服务税 |
| 代扣税 | ภาษีหัก ณ ที่จ่าย | Withholding tax | 付款方扣下并缴给税务局的税款 |
