# เงินเดือน: ภาษีเงินได้บุคคลธรรมดาและประกันสังคม

นายจ้างต้องหักภาษีเงินได้บุคคลธรรมดาจากเงินเดือนทุกเดือน จ่ายเงินสมทบประกันสังคมทั้งสองฝ่าย และยื่นแบบกับสองหน่วยงาน: กรมสรรพากร และสำนักงานประกันสังคม (สปส.)

## อัตราภาษีเงินได้บุคคลธรรมดา

ภาษีเป็นอัตราก้าวหน้า: เงินได้สุทธิแต่ละช่วงเสียภาษีในอัตราของช่วงนั้น

| เงินได้สุทธิ (บาทต่อปี) | อัตรา |
| --- | --- |
| 0 – 150,000 | ยกเว้น |
| 150,001 – 300,000 | 5% |
| 300,001 – 500,000 | 10% |
| 500,001 – 750,000 | 15% |
| 750,001 – 1,000,000 | 20% |
| 1,000,001 – 2,000,000 | 25% |
| 2,000,001 – 5,000,000 | 30% |
| เกิน 5,000,000 | 35% |

แหล่งที่มา: [PwC Worldwide Tax Summaries](https://taxsummaries.pwc.com/thailand/individual/taxes-on-personal-income)

**เงินได้สุทธิ** = เงินเดือนทั้งปี − ค่าใช้จ่าย (50% ของเงินเดือน ไม่เกิน 100,000 บาท) − ค่าลดหย่อน ค่าลดหย่อนส่วนตัว 60,000 บาท นอกจากนี้ยังมีค่าลดหย่อนคู่สมรส บุตร บิดามารดา เงินสมทบประกันสังคม เบี้ยประกันชีวิต กองทุนสำรองเลี้ยงชีพ และอื่น ๆ

ตัวอย่าง: พนักงานเงินเดือน 30,000 บาท (360,000 บาทต่อปี) ใช้เพียงค่าลดหย่อนส่วนตัวและประกันสังคม (875 × 12 = 10,500)

| ขั้นตอน | บาท |
| --- | --- |
| เงินเดือนทั้งปี | 360,000 |
| หักค่าใช้จ่าย (50% ไม่เกิน 100,000) | (100,000) |
| หักค่าลดหย่อนส่วนตัว | (60,000) |
| หักประกันสังคม | (10,500) |
| **เงินได้สุทธิ** | **189,500** |
| ภาษี: 150,000 แรกยกเว้น 39,500 ถัดไป 5% | **1,975 บาทต่อปี (ประมาณ 165 บาทต่อเดือน)** |

นายจ้างประมาณภาษีทั้งปีทุกเดือนแล้วหักไว้หนึ่งในสิบสอง

## แบบที่นายจ้างต้องยื่น

| แบบ | รายละเอียด | กำหนด |
| --- | --- | --- |
| ภ.ง.ด.1 | ภาษีที่หักจากเงินเดือนรายเดือน | ภายในวันที่ 7 ของเดือนถัดไป (15 หากยื่นออนไลน์) |
| ภ.ง.ด.1ก | สรุปเงินได้และภาษีของพนักงานแต่ละคนทั้งปี | ภายในสิ้นเดือนกุมภาพันธ์ |
| 50 ทวิให้พนักงาน | หนังสือรับรองเงินได้และภาษีที่หักประจำปี | ต้นปี เพื่อให้พนักงานยื่นภาษีเองได้ |

จากนั้นพนักงานยื่น **ภ.ง.ด.91** ประจำปีเองภายใน 31 มีนาคม (ยื่นออนไลน์ได้เพิ่ม 8 วัน) และขอคืนภาษีหากมี

## กองทุนประกันสังคม

- นายจ้างและลูกจ้างจ่ายฝ่ายละ **5% ของค่าจ้างรายเดือน**
- ตั้งแต่ 1 มกราคม 2569 ฐานค่าจ้างต่ำสุด 1,650 บาท สูงสุด **17,500 บาท** เงินสมทบสูงสุดจึงเป็น **875 บาท** ต่อฝ่ายต่อเดือน (เดิม 750 บาท) เพดานจะเพิ่มเป็น 20,000 บาทในปี 2572 และ 23,000 บาทในปี 2575 ([Baker McKenzie](https://www.bakermckenzie.com/en/insight/publications/alerts/2025/12/thailand-higher-wage-base-for-ssf-contributions))
- แจ้งขึ้นทะเบียนพนักงานใหม่กับ สปส. ภายใน 30 วันนับจากวันเริ่มงาน
- ยื่นแบบและชำระเงินสมทบ (สปส.1-10) ภายใน **วันที่ 15 ของเดือนถัดไป**

นายจ้างยังต้องจ่ายเงินสมทบ **กองทุนเงินทดแทน** ประจำปี ซึ่งคุ้มครองการบาดเจ็บจากการทำงาน อัตราขึ้นอยู่กับประเภทกิจการ
