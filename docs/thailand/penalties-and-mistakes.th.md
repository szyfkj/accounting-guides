# บทลงโทษและข้อผิดพลาดที่พบบ่อย

ภาษีที่ชำระล่าช้ามีต้นทุนสูง: ต้องเสีย **เงินเพิ่มร้อยละ 1.5 ต่อเดือน** (ไม่เกินจำนวนภาษี) นอกเหนือจากเบี้ยปรับและค่าปรับ การยื่นแบบตรงเวลา แม้ไม่มีภาษีต้องชำระ ช่วยหลีกเลี่ยงส่วนใหญ่ได้

## บทลงโทษหลัก

| ปัญหา | ผลที่ตามมา |
| --- | --- |
| ชำระภาษีล่าช้า | เงินเพิ่มร้อยละ 1.5 ต่อเดือนหรือเศษของเดือนของภาษีที่ค้าง (มาตรา 27 ประมวลรัษฎากร) |
| ยื่นแบบล่าช้า | ค่าปรับทางอาญา (โดยทั่วไปไม่เกิน 2,000 บาทต่อแบบ) บวกเงินเพิ่มของภาษีที่ค้าง |
| ยื่น VAT ขาดหรือไม่ยื่น | เบี้ยปรับสูงสุด 2 เท่าของภาษี ลดลงได้หากยื่นเองก่อนกรมสรรพากรติดต่อ บวกเงินเพิ่ม |
| ไม่ออกใบกำกับภาษี หรือออกโดยไม่ได้จด VAT | เบี้ยปรับ 2 เท่าของภาษี และค่าปรับ |
| ไม่หักภาษี ณ ที่จ่าย หรือหักแล้วไม่นำส่ง | ผู้จ่ายต้องรับผิดชำระภาษีนั้นเอง บวกเงินเพิ่ม และรายจ่ายอาจถูกตัดออก |
| ไม่จัดทำบัญชี หรือไม่ยื่นงบการเงินต่อ DBD | ค่าปรับบริษัทตาม พ.ร.บ.การบัญชี และค่าปรับกรรมการแยกต่างหาก |

จำนวนเงินกำหนดโดยกฎหมายและอาจเปลี่ยนแปลง กรมสรรพากรมีหลักเกณฑ์ลดเบี้ยปรับสำหรับการยื่นล่าช้าโดยสมัครใจ

## ข้อผิดพลาดที่ผู้ไม่ใช่นักบัญชีมักทำ

1. **ปนเงินส่วนตัวกับเงินธุรกิจ** ใช้บัญชีธนาคารแยกของบริษัท ค่าใช้จ่ายส่วนตัวผ่านบริษัทหักภาษีไม่ได้ และอาจถือเป็นเงินได้ของกรรมการ
2. **รับใบกำกับภาษีซื้อที่ข้อมูลผิด** ไม่มีเลขผู้เสียภาษีหรือสาขาผิด หมายถึงขอคืนภาษีซื้อไม่ได้
3. **ลืมหักภาษี ณ ที่จ่าย** จากค่าบริการและค่าเช่า แล้วต้องจ่ายภาษีแทนเอง
4. **ไม่เก็บ 50 ทวิ** จากลูกค้า ทำให้เครดิตภาษีที่ถูกหักไปแล้วไม่ได้
5. **ไม่สังเกตเกณฑ์จด VAT** เมื่อรายได้เกิน 1.8 ล้านบาท คุณต้องเสีย VAT จากยอดขายไม่ว่าจะเรียกเก็บจากลูกค้าหรือไม่
6. **คิดว่าเงินในธนาคารคือกำไร** ส่วนหนึ่งคือ VAT ภาษีหัก ณ ที่จ่าย และประกันสังคมที่เป็นของรัฐ
7. **ปล่อยทุกอย่างไว้จนสิ้นปี** การทำบัญชีและกระทบยอดธนาคารทุกเดือนทำให้การตรวจสอบบัญชีเร็วและถูกลง
8. **ลงนามเอกสารที่ไม่เข้าใจ** กรรมการต้องรับผิดส่วนตัวสำหรับการยื่นแบบบางประเภท แม้สำนักงานบัญชีเป็นผู้จัดทำ
