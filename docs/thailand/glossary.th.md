# อภิธานศัพท์

| ไทย | อังกฤษ | ความหมาย |
| --- | --- | --- |
| กำไรสะสม | Retained earnings | กำไรในอดีตที่เก็บไว้ในกิจการ |
| ค่าใช้จ่าย | Expense | ต้นทุนที่ใช้ไปเพื่อก่อให้เกิดรายได้ |
| ค่าเสื่อมราคา | Depreciation | การเฉลี่ยต้นทุนสินทรัพย์ตามอายุการใช้งาน |
| งบการเงิน | Financial statements | รายงานประจำปีที่สรุปบัญชี |
| งบกำไรขาดทุน | Income statement | รายงานรายได้ ค่าใช้จ่าย และกำไรของงวด |
| งบทดลอง | Trial balance | รายการยอดคงเหลือทุกบัญชี เดบิตต้องเท่ากับเครดิต |
| งบแสดงฐานะการเงิน | Balance sheet | รายงานสินทรัพย์ หนี้สิน และส่วนของเจ้าของ ณ วันหนึ่ง |
| เจ้าหนี้การค้า | Accounts payable | เงินที่ค้างจ่ายผู้ขาย |
| เกณฑ์คงค้าง | Accrual basis | บันทึกรายได้เมื่อเกิดสิทธิ และค่าใช้จ่ายเมื่อเกิดขึ้น |
| เครดิต | Credit | ด้านขวาของรายการ เพิ่มหนี้สิน ส่วนของเจ้าของ และรายได้ |
| เลขประจำตัวผู้เสียภาษีอากร | Tax ID | เลข 13 หลักประจำตัวผู้เสียภาษี |
| เดบิต | Debit | ด้านซ้ายของรายการ เพิ่มสินทรัพย์และค่าใช้จ่าย |
| ต้นทุนขาย | Cost of goods sold | ต้นทุนทางตรงของสินค้าที่ขายในงวด |
| ทุนชำระแล้ว | Paid-up capital | ทุนเรือนหุ้นที่ผู้ถือหุ้นชำระจริง |
| บัญชีแยกประเภท | General ledger | บันทึกรายการทั้งหมดจัดกลุ่มตามบัญชี |
| ประกันสังคม | Social security | ประกันของรัฐที่นายจ้างและลูกจ้างร่วมสมทบ |
| ผังบัญชี | Chart of accounts | รายชื่อบัญชีทั้งหมดพร้อมรหัส |
| ผู้ทำบัญชี | Bookkeeper | ผู้รับผิดชอบบันทึกรายการตาม พ.ร.บ.การบัญชี |
| ผู้สอบบัญชีรับอนุญาต | Auditor (CPA) | ผู้ตรวจสอบงบการเงินอิสระที่มีใบอนุญาต |
| ภาษีขาย | Output VAT | VAT ที่เรียกเก็บจากการขาย |
| ภาษีซื้อ | Input VAT | VAT ที่จ่ายเมื่อซื้อ |
| ภาษีเงินได้นิติบุคคล | Corporate income tax | ภาษีจากกำไรสุทธิของบริษัท |
| ภาษีเงินได้บุคคลธรรมดา | Personal income tax | ภาษีจากเงินได้ของบุคคล |
| ภาษีมูลค่าเพิ่ม | VAT | ภาษี 7% จากสินค้าและบริการ เก็บโดยผู้ประกอบการจดทะเบียน |
| ภาษีหัก ณ ที่จ่าย | Withholding tax | ภาษีที่ผู้จ่ายหักไว้และนำส่งกรมสรรพากร |
| รอบบัญชี | Accounting period | ระยะเวลา 12 เดือนของงบการเงินหนึ่งชุด |
| รายได้ | Revenue | รายได้จากการขายสินค้าและบริการ |
| ลูกหนี้การค้า | Accounts receivable | เงินที่ลูกค้าค้างชำระ |
| สมุดรายวัน | Journal | สมุดบันทึกขั้นต้นตามลำดับวันที่ |
| ส่วนของผู้ถือหุ้น | Equity | ส่วนได้เสียของเจ้าของ: ทุนบวกกำไรสะสม |
| สินค้าคงเหลือ | Inventory | สินค้าที่มีไว้เพื่อขาย |
| สินทรัพย์ | Asset | สิ่งที่กิจการเป็นเจ้าของหรือควบคุมและมีมูลค่า |
| หนี้สิน | Liability | สิ่งที่กิจการเป็นหนี้ |
| ใบกำกับภาษี | Tax invoice | เอกสาร VAT ที่ผู้ขายที่จดทะเบียนออกให้ |
