# 泰国常见业务分录示例

以下分录展示泰国的增值税、预提税和社保如何体现在账簿中，均为已登记增值税的公司的常见业务，金额单位为泰铢。记账规则见 [借方与贷方](../fundamentals/debits-and-credits.md)。

**a) 赊销服务 10,000 + 7% 增值税**

| 账户 | 借 | 贷 |
| --- | --- | --- |
| 应收账款 | 10,700 |  |
| 服务收入 |  | 10,000 |
| 销项税额 |  | 700 |

**b) 客户付款，并按 10,000 服务费代扣 3% 预提税**

| 账户 | 借 | 贷 |
| --- | --- | --- |
| 银行存款 | 10,400 |  |
| 预缴预提税（资产） | 300 |  |
| 应收账款 |  | 10,700 |

这 300 泰铢并没有损失。客户替你缴给税务局，并开具代扣税证明。你之后可以用它抵减企业所得税。

**c) 购买办公用品 2,000 + 7% 增值税，转账支付**

| 账户 | 借 | 贷 |
| --- | --- | --- |
| 办公用品费 | 2,000 |  |
| 进项税额 | 140 |  |
| 银行存款 |  | 2,140 |

**d) 发放月薪 50,000，扣除社保 875 和个人所得税 1,700**

| 账户 | 借 | 贷 |
| --- | --- | --- |
| 工资费用 | 50,000 |  |
| 应付社保 |  | 875 |
| 应交代扣税（PND 1） |  | 1,700 |
| 银行存款 |  | 47,425 |

雇主还需缴纳自己承担的 875 泰铢社保：借 社保费用 875，贷 应付社保 875。次月公司向社会保障办公室和税务局缴款后，这两项应付款即结清。

每笔分录都要检查借方合计是否等于贷方合计。如果不相等，说明有错误。
