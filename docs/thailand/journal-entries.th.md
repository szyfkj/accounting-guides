# ตัวอย่างการบันทึกบัญชีรายการค้าทั่วไปในไทย

ตัวอย่างต่อไปนี้แสดงว่า VAT ภาษีหัก ณ ที่จ่าย และประกันสังคมของไทยปรากฏในบัญชีอย่างไร กฎการบันทึกดูได้ที่ [เดบิตและเครดิต](../fundamentals/debits-and-credits.md)

รายการต่อไปนี้เป็นรายการทั่วไปของบริษัทไทยที่จดทะเบียนภาษีมูลค่าเพิ่ม จำนวนเงินเป็นบาท

**ก) ขายบริการ 10,000 + VAT 7% เป็นเงินเชื่อ**

| บัญชี | Dr | Cr |
| --- | --- | --- |
| ลูกหนี้การค้า | 10,700 |  |
| รายได้ค่าบริการ |  | 10,000 |
| ภาษีขาย |  | 700 |

**ข) ลูกค้าชำระเงิน โดยหักภาษี ณ ที่จ่าย 3% ของค่าบริการ 10,000**

| บัญชี | Dr | Cr |
| --- | --- | --- |
| เงินฝากธนาคาร | 10,400 |  |
| ภาษีเงินได้ถูกหัก ณ ที่จ่าย (สินทรัพย์) | 300 |  |
| ลูกหนี้การค้า |  | 10,700 |

เงิน 300 บาทไม่ได้หายไป ลูกค้านำส่งกรมสรรพากรแทนคุณและออกหนังสือรับรองการหักภาษี ณ ที่จ่ายให้ คุณนำไปเครดิตภาษีเงินได้นิติบุคคลภายหลังได้

**ค) ซื้อวัสดุสำนักงาน 2,000 + VAT 7% จ่ายโดยโอนเงิน**

| บัญชี | Dr | Cr |
| --- | --- | --- |
| ค่าวัสดุสำนักงาน | 2,000 |  |
| ภาษีซื้อ | 140 |  |
| เงินฝากธนาคาร |  | 2,140 |

**ง) จ่ายเงินเดือน 50,000 หักประกันสังคม 875 และภาษีเงินได้บุคคลธรรมดา 1,700**

| บัญชี | Dr | Cr |
| --- | --- | --- |
| เงินเดือน | 50,000 |  |
| ประกันสังคมค้างจ่าย |  | 875 |
| ภาษีหัก ณ ที่จ่ายค้างจ่าย (ภ.ง.ด.1) |  | 1,700 |
| เงินฝากธนาคาร |  | 47,425 |

นายจ้างยังต้องจ่ายเงินสมทบประกันสังคมส่วนของตนเอง 875 บาท: Dr ค่าประกันสังคม 875, Cr ประกันสังคมค้างจ่าย 875 หนี้ค้างจ่ายทั้งสองรายการจะหมดไปเมื่อบริษัทนำส่งสำนักงานประกันสังคมและกรมสรรพากรในเดือนถัดไป

ทุกรายการให้ตรวจว่ายอดรวมช่อง Dr เท่ากับช่อง Cr หากไม่เท่า แสดงว่ามีข้อผิดพลาด
