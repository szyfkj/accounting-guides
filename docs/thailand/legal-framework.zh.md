# 泰国记账法律框架

主要规则由两个机构制定。商业部下属的 **商业发展厅（DBD，กรมพัฒนาธุรกิจการค้า）** 依据《会计法》（佛历 2543 年，即 2000 年）监管记账和财务报表。财政部下属的 **税务局（RD，กรมสรรพากร）** 依据《税法典》征税。

## 企业形式及其义务

| 形式 | 纳税方式 | 是否须按《会计法》记账 | 审计 |
| --- | --- | --- | --- |
| 个体经营者 | 个人所得税 | 否（只需简单收支记录；若已登记增值税，需做每日报告） | 无 |
| 普通（未注册）合伙 | 个人所得税 | 否 | 无 |
| 注册普通合伙或有限合伙 | 企业所得税 | 是 | 注册会计师（CPA）；若资本 ≤ 500 万、资产 ≤ 3,000 万且收入 ≤ 3,000 万泰铢，可由税务审计师（TA）审计 |
| 私人有限公司（บริษัทจำกัด） | 企业所得税 | 是 | 每年由注册会计师（CPA）审计 |
| 大众有限公司 | 企业所得税 | 是 | 上市公司须由证监会（SEC）认可的 CPA 审计 |
| 外国公司分支机构 | 企业所得税 | 是 | CPA |

## 会计准则

泰国财务报表遵循泰国会计职业联合会（TFAC）制定的泰国财务报告准则：

- **完整版 TFRS** 适用于公众利益实体：上市公司、银行、保险公司等。
- **TFRS for NPAEs**（非公众利益实体）适用于大多数私人中小企业，更简单：无需现金流量表、以成本计量、披露要求更少。

## 公司的主要义务

- **任命合格的记账人（ผู้ทำบัญชี）。** 记账人须在 DBD 登记并达到最低学历要求。可由内部员工或会计公司担任，但董事仍对账簿负责。
- **及时登记账簿**，并存放于注册办公地点或已通知 DBD 的其他地点。
- **每 12 个月结账一次。**
- **年度财务报表须经审计**，并在年度结束后 4 个月内由年度股东大会（AGM）批准。
- **向 DBD 申报**（通过 DBD e-Filing）：AGM 后 1 个月内提交经审计的财务报表（ส.บ.ช.3），AGM 后 14 天内提交股东名册（บอจ.5）。
- **账簿和凭证至少保存 5 年**（自年度结束起算），主管官员可要求延长至 7 年。

未按时向 DBD 申报，公司和董事都会被罚款，因此要像对待报税期限一样重视这些期限。
