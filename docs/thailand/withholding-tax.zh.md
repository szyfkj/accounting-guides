# 预提所得税 / 代扣税（WHT，ภาษีหัก ณ ที่จ่าย）

公司支付某些服务费、租金及其他收入时，必须 **从付款中按比例扣除税款，并代收款方缴给税务局**。这是收款方所得税的预缴，而不是额外的税：收款方可以用它抵减自己的企业所得税或个人所得税。

代扣税按 **不含增值税** 的金额计算，一般适用于 1,000 泰铢及以上的付款。

## 向泰国公司付款的常见税率

| 付款类型 | 税率 |
| --- | --- |
| 服务费、专业服务费、承包费 | 3% |
| 房产或设备租金 | 5% |
| 广告费 | 2% |
| 运输费（非公共交通） | 1% |
| 利息 | 1% |
| 奖金及促销奖品 | 5% |
| 股息 | 10% |

向个人和境外公司付款的税率不同。向境外支付服务费、特许权使用费和利息一般代扣 15%，股息 10%，除非税收协定规定更低税率。（[Forvis Mazars](https://forvismazars.com/th/en/insights/doing-business-in-thailand/tax/withholding-tax-in-thailand)）

**电子代扣税（e-Withholding Tax）：** 通过银行 e-WHT 系统付款，只需代扣 1%（而非 2–5%），并由银行代为申报。内阁已批准将此优惠延长至 2026 年 1 月 1 日至 2027 年 12 月 31 日，但尚需在皇家公报上发布，使用前请确认。（[Forvis Mazars](https://www.forvismazars.com/th/en/insights/doing-business-in-thailand/tax/thailand-extends-e-tax-and-e-donation-incentives)）

## 应申报的表格

| 表格 | 适用于向以下对象付款 |
| --- | --- |
| PND 1（ภ.ง.ด.1） | 员工（工资） |
| PND 2（ภ.ง.ด.2） | 取得股息或利息的个人 |
| PND 3（ภ.ง.ด.3） | 个人（自由职业者、房东、承包人） |
| PND 53（ภ.ง.ด.53） | 泰国公司及法人合伙企业 |
| PND 54（ภ.ง.ด.54） | 未在泰国经营的境外公司 |

在 **次月 7 日** 前申报并缴税（电子申报为 15 日）。

## 50 Tawi 代扣税证明（50 ทวิ）

付款方必须向收款方开具代扣税证明，因《税法典》第 50 条之二而俗称"50 Tawi"。作为收款方，**请收集并归档收到的每一份证明**：它是你在 PND 50 中抵减企业所得税的凭证。缺少证明可能导致同一笔税缴两次。

示例：你向一家泰国营销公司支付服务费 50,000 泰铢 + 增值税 3,500。代扣 50,000 的 3% = 1,500 泰铢，向对方转账 52,000 泰铢，在 7 日前（电子申报 15 日）申报 PND 53，并向对方开具 1,500 泰铢的 50 Tawi。
